Module map_parser 

Source

ETS2 map sector text parser.

Parses the text-based map sector format produced by the ETS2 map editor (edit_save_text). This format contains node {}, road {}, and prefab {} blocks with UIDs and position data.

The parsed data feeds directly into MapData for graph building.
