TruckPilot — autopilot, map-export and tooling library for Euro Truck Simulator 2.

The crate is organised into a few coherent layers:

  • Map / graph pipeline: ets2_parser, pipeline, graph_schema, graph_export, compat_export, json_export.
  • Routing: autopilot (A* on GraphData), route_smoothing.
  • Live runtime: autopilot_loop, controller, acc_controller, telemetry, shm_telemetry, vjoy.
  • Configuration: config.
