Module shm_telemetry 

Source
Expand description

Shared memory telemetry reader for the TruckPilot native plugin.

The native C++ plugin writes a fixed-layout struct into a named shared memory region (Windows: Local\TruckPilotTelemetry, Linux: /truckpilot_telemetry). This module reads that region and converts it into TelemetryData.

Falls back gracefully if the shared memory is not available (plugin not running).
