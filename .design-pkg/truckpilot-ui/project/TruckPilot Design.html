TruckPilot v0.3 · design polish Senior Product Designer 2026-05-18

A cockpit, not a
dashboard.

TruckPilot drives a 40-ton truck on your behalf. The UI should look like something you'd trust to do that — geometric, telemetry-dense, calm at rest, decisive in motion. The brand gradient is the only thing that shouts; everything else gets out of the way.

01

Brand gradient

Sampled directly from the logo. Used sparingly: engaged state of the autopilot, sparkline glows, primary CTAs, the route polyline, the active sidebar rail. Never as a page background — the brand is a signal, not a wallpaper.

Voice
Plain, technical, confident. Same tone as flight-deck callouts: "Engaged", "Cruise active", "Telemetry lost". Never marketing copy, never exclamation marks.
Geometry
Logo is constructive — circle, triangle, sharp cuts. UI mirrors that: 6/10px radii, 1px hairlines, no fluffy rounding, no decorative shadows.
Dark-first
Dark theme is hero — the gradient lives there. Light theme is a real design, not a colour invert: it keeps the gradient on accents and ditches the glows.

Migration order

Phase 1 · Foundation ~3 days
  1. Drop in tokens.css and wire Tailwind @theme
  2. Load Geist + Geist Mono
  3. Restyle Button/Card/Switch/Tabs primitives
  4. Theme sonner toasts
  5. App shell: titlebar, sidebar groups, footer
Phase 2 · Dashboard ~5 days
  1. EngageButton + PreconditionPill (most visible win)
  2. BigNumber + Sparkline → wire Speed/RPM
  3. VJoyBar + FailsafeBanner
  4. NaviStatusCard (replace Goal-UID)
  5. SpeedSign + recent-signs strip
Phase 3 · Detail pages ~4 days
  1. Plugins list + detail
  2. Blackboard tree + inspector
  3. Logs toolbar + virtualized stream
  4. PID with live-response chart
  5. Settings rebuild + Diag override
Phase 4 · Roadmap ~10 days
  1. RouteMap with debug node layer
  2. LaneCam overlay
  3. DiagnosticsPanel
  4. SignDetection gallery
  5. ETS2 status indicator (footer)
Performance notes
  • Sparklines on raf-batched ringbufs, never per-sample setState. Target <0.8ms/frame.
  • VJoyBar uses CSS transform:translateX, not width — keeps it off the layout pass.
  • Engage gradient pulse uses box-shadow alpha animation, not blur. Cheap.
  • Pause animations when window is hidden via visibilitychange.
  • Every animated element honours prefers-reduced-motion.
